Making My Website Accessible

I designed my Haiti website with accessibility in mind so that different types of users can access and understand the information. I use clear headings, readable text, descriptive links, alternative text for images, and organized sections throughout the website.

My goal is to make the website easier to use for visitors with different needs and abilities.

Sound, Screen Description, and Page Reading

This website provides accessibility options that allow visitors to listen to information on the page. Users can choose to hear a description of the page or have the page text read aloud.

The screen description provides a summary of the page, while the page reading option reads the written content on the page aloud.

Accessibility Features

  • Alternative Text: Images include descriptive alt text so screen readers can describe the images to users.
  • Keyboard Navigation: Links, buttons, and form controls can be accessed using the keyboard without requiring a mouse.
  • Readable Text: The website uses readable text and sufficient spacing between sections.
  • Proper Headings: Headings are organized using h1 and h2 elements to create a logical page structure.
  • Descriptive Links: Links clearly explain where they will take the visitor.
  • Color and Contrast: Text and backgrounds are designed to provide enough contrast for easier reading.
  • Form Labels: Form fields on the Contact Us page have labels to help visitors understand what information should be entered.
  • Page Reading: Visitors can use the page-reading button to have the main content read aloud.
  • Screen Description: Visitors can listen to a short description explaining the purpose and accessibility features of this page.

WCAG Guidelines

My website follows basic principles from the Web Content Accessibility Guidelines (WCAG). These principles include making content perceivable, operable, understandable, and robust. Accessibility helps make the website easier for people with different abilities to use.

Making My Website Accessible

I designed my Haiti website with accessibility in mind so that different types of users can access and understand the information.

I use clear headings, readable text, descriptive links, alternative text for images, and organized sections throughout the website.

My goal is to make the website easier to use for visitors with different needs and abilities.

Accessibility Tools

This website provides tools that allow visitors to listen to information on the page. These tools can be helpful for visitors who have difficulty reading the written information on the screen.

The screen description provides a short summary of this page. The page-reading option reads the written content on the page aloud.

Audio Description

Visitors can use the audio player below to listen to an audio description about accessibility on this website.

If the audio file is not available, visitors can use the Read Screen Description or Read This Page buttons instead.

Accessibility Features

The following accessibility features are included in my website:

  • Alternative Text: Images include descriptive alt text so screen readers can describe the images to visitors.
  • Keyboard Navigation: Links, buttons, and form controls can be accessed using a keyboard without requiring a mouse.
  • Readable Text: The website uses readable text, appropriate spacing, and organized sections.
  • Proper Headings: Headings are organized using h1 and h2 elements to create a logical page structure.
  • Descriptive Links: Links clearly explain where they will take visitors.
  • Color and Contrast: Text and backgrounds use contrasting colors to make information easier to read.
  • Form Labels: Form fields on the Contact page have labels to help visitors understand what information should be entered.
  • Page Reading: Visitors can use the page-reading button to have the main content read aloud.
  • Screen Description: Visitors can listen to a short description explaining the purpose and accessibility features of this page.

Accessible Images

Images on the website include alternative text. Alternative text helps visitors who use screen readers understand the subject and purpose of an image.

The alternative text describes the image so that a screen reader can communicate information about the photograph to someone who cannot see it.

Web Content Accessibility Guidelines

My website follows basic principles from the Web Content Accessibility Guidelines, also known as WCAG.

WCAG focuses on making web content perceivable, operable, understandable, and robust. Following these principles helps make websites easier for people with different abilities to use.

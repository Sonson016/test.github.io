Making My Website Accessible

Accessibility is important because websites should be usable by as many people as possible, including people who use assistive technology.

I designed this website with clear headings, organized sections, readable text, descriptive links, alternative text for images, and keyboard-friendly navigation.

Accessibility Tools

This website includes tools that can help users access information on the pages.

Audio Description

An audio description is also provided to help explain information about the website.

Accessibility Features

  • Clear page headings
  • Organized sections
  • Keyboard-friendly navigation
  • Skip-to-content link
  • Descriptive links
  • Alternative text for images
  • Readable text and spacing
  • Responsive design for smaller screens

Accessible Images

Images on this website include alternative text. Alternative text helps users who cannot see an image understand what the image represents.

Web Content Accessibility Guidelines

Web Content Accessibility Guidelines, commonly called WCAG, provide recommendations for making websites more accessible.

My website uses several accessibility practices inspired by these guidelines, including readable content, keyboard navigation, alternative text, clear headings, and descriptive links.

Accessibility Feedback

If you experience an accessibility problem while using this website, please visit the Contact page and send feedback.
